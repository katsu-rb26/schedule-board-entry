プライバシーポリシー

本ポリシーは、Schedule Board（勤務スケジュール管理ウェブアプリ。以下「本サービス」）において、利用者の情報をどのように取り扱うかを定めるものです。

1. 取得する情報

本サービスは、Googleアカウントでログインした際に Google から提供される、次の情報のみを取得します。

  • メールアドレス
  • 氏名（表示名）

Googleアカウントのパスワードは、本サービスが取得・保存することはありません。

2. 利用目的

取得した情報は、次の目的にのみ利用します。

  • ログイン時の本人確認
  • 勤務スケジュールの閲覧・編集を許可された利用者かどうかの確認

3. Googleのユーザーデータへのアクセス

本サービスは、ログインの際に Google スプレッドシート、Google カレンダー、Google ドライブ等、利用者の Google アカウント内のデータへ、利用者の権限でアクセスすることはありません。ログインでは本人確認に必要な情報のみを使用します。

4. 情報の保存

ログイン状態を保つための情報（入場証）を、利用者の端末のブラウザ内に最大30日間保存します。ログアウトを行うと、この情報は端末から削除されます。

5. 第三者への提供

取得した情報を、第三者に提供・販売することはありません。また、広告利用のために使用することもありません。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本サービスによる Google のユーザーデータの利用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。
